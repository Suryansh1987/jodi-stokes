# 2. Real Products Section

Status: Complete
Depends On: Task 1

## Goal

Replace the separate Book and mock Shop surfaces with one `Products` section that prominently features the Water Exercise Book and lists only the three additional approved products.

## Context

- `app/(public)/page.tsx` currently renders `BookSection` followed by `ShopSection`.
- `BookSection` has useful featured-product layout, `next/image`, feature rows, and CTA styling, but its three purchase links point to `#`.
- `ShopSection` is tightly coupled to eight fake products, CSS art variants, fake category filters, favorites, colors, availability, shipping, and add-to-cart controls.
- `components/ui/card.tsx` and `SectionIntro` are reusable for the three secondary products.
- The only approved product asset currently available is `public/images/jodi/book-water-exercise.png`.

## Files / Areas Likely Involved

- `app/(public)/page.tsx`
- `components/sections/home/book-section.tsx` (rename or replace with `products-section.tsx`)
- `components/sections/home/shop-section.tsx`
- `lib/content/home.ts`
- `lib/content/programs-products.json`
- `lib/content/programs-products.ts`
- Product/book selectors in `app/globals.css`
- Product and home-composition assertions in `test/home.spec.ts`

## Required Changes

- Replace the two rendered sections with one section using `id="products"` and an accurate `Products` heading.
- Preserve and adapt the current book showcase as the featured product; keep its real cover image and visual prominence.
- Render Lunch Bag, Water Bottle, and Small Towel as secondary product cards from centralized JSON.
- Reuse `SectionIntro`, shadcn `Card`, responsive layout patterns, `next/image`, and existing button/link styles where they still fit.
- Render an external anchor only when `externalUrl` is present. Use approved CTA wording such as `View product` or `Purchase externally`; make external behavior clear and apply `rel="noopener noreferrer"` if a new tab is used.
- For missing URLs, render a noninteractive honest state without `href="#"`, click handlers, or disabled anchors.
- Omit unconfirmed price, description, or image regions cleanly. Do not display supplier cost or reuse mock CSS merchandise art as though it depicts the real products.
- Remove `ShopSection` from home composition and delete/simplify its now-unused component and content exports.
- Remove obsolete shop/product CSS while retaining reusable card/book styles needed by Products.
- Update focused Playwright coverage for exactly four products, featured book image loading, external/missing-link behavior, responsive layout, and no overflow.

## Explicit Non-Goals

- No cart, checkout, payments, inventory, shipping, refunds, order handling, favorites, variants, filters, Amazon API, or accounts.
- No product detail routes or runtime product API.
- No fabricated product photos, URLs, descriptions, or prices.
- No Programs/registration or navigation cleanup beyond what is necessary to render the new section; Task 5 owns site-wide stale links.

## Data / Client Requirements

- Only Water Exercise Book, Lunch Bag, Water Bottle, and Small Towel may render.
- Book remains the featured product.
- Lunch Bag public price needs confirmation; `$5.95` must never render unless the client explicitly identifies it as public pricing.
- Water Bottle and Small Towel prices are unconfirmed.
- All external URLs and all non-book product photos/descriptions remain client dependencies.

## Edge Cases

- A product with no external URL remains visible but cannot imply it is purchasable now.
- Cards with missing price/description/image must retain stable responsive dimensions without empty decorative shells.
- External URLs must use only `http:` or `https:` values supplied through the typed content layer.
- Long third-party CTA labels and product names must not overflow on mobile.

## Verification

- Update and run the focused product Playwright test on desktop and mobile.
- Assert there are exactly four approved products and no former mock product names.
- Assert the section has one `#products` target and no rendered `#shop` section.
- Assert no cart, favorites, filter, stock, shipping, color, or add-to-cart controls remain.
- Assert products without URLs are not links; test a supplied external URL when available.
- Run `npm run lint`, `npm run build`, relevant `npm run test:e2e`, and `git diff --check`.

## Completion Criteria

- One Products section replaces Book plus Shop.
- Only approved products render from centralized data.
- The book remains visually featured.
- Purchase behavior is external-only and honest when URLs are missing.
- Mock storefront UI and unused code are removed.
